# Яндекс Директ: материалы для поисковой кампании

Посадочные: `/zakazat-marketingovoe-issledovanie/` (главная под запросы «заказать»), `/agentstvo-marketingovyh-issledovanij/`, `/b2b-issledovaniya/`, страницы услуг `/uslugi/...`.
UTM-шаблон: `?utm_source=yandex&utm_medium=cpc&utm_campaign={campaign_id}&utm_content={ad_id}&utm_term={keyword}`.
Цель в Метрике: `lead_submit` (оптимизация на конверсии). Маркировка рекламы (ERID, ОРД) и запуск за владельцем.

## Настройки кампании (рекомендации)
- Тип: поисковая кампания (без РСЯ на старте).
- Регион: Россия; при ограниченном бюджете сначала Москва и Санкт-Петербург.
- Стратегия: сначала «Максимум кликов» с недельным бюджетом и ограничением цены клика, после 15–20 заявок переход на оптимизацию по цели lead_submit.
- Расписание: рабочие часы и вечер, ночью можно снижать ставки.
- Корректировки: мобильные не снижать (форма и кнопка звонка на телефоне работают).
- Объявления на разные группы: по 2–3 варианта для A/B, менять через 2 недели по CTR.
- Следить: поисковые запросы раз в неделю, расширять минус-слова.
